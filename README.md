# TooDue — Task Manager
 
A full-stack MERN task manager with JWT authentication, built as a learning project.
 
**Live Demo:** [toodue-frontend.vercel.app](https://toodue-frontend.vercel.app)
 
---
 
## Tech Stack
 
**Frontend**
- React + Vite
- React Router DOM
- Tailwind CSS

**Backend**
- Node.js + Express
- MongoDB + Mongoose
- JWT (HTTP-only cookies)
- bcrypt

**Deployed on**
- Frontend — Vercel
- Backend — Render
- Database — MongoDB Atlas
---
 
## Features
 
- User registration and login with JWT auth
- HTTP-only cookie session management
- Protected routes — dashboard only accessible when logged in
- Create, read, update, and delete tasks
- Mark tasks as complete — auto-separates into pending and completed
- Error handling on all API calls
- Responsive minimal UI
